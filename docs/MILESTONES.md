# 里程碑

里程碑按依赖推进，不绑定虚构日期。每一项只有满足验收条件才算完成。

## 仓库结构清理

状态：完成。

验收条件：

- 核心实现全部位于 `src/demo_graph_lab/`；
- 包按 demo、graph、policy、selection、execution、evaluation 分工；
- 没有旧实现双树或重复状态文档；
- 全部单测通过，两个 CLI 的 `--help` 可运行；
- README、API 和实际 import path 一致。

## 真实候选链

状态：未开始。

验收条件：

- 从真实 RGB-D/点云输入生成多个 grasp candidates；
- 硬过滤能报告可达、碰撞和夹爪宽度失败；
- demo region/cone 排序进入真实选择路径；
- 没有候选时直接失败，不回退到手写 pose。

止损：如果候选源本身不能覆盖可行抓取，先修候选生成，不评估排序算法。

## 非特权 Runtime

状态：未开始。

验收条件：

- 新 runtime 只读取传感器、感知结果、机器人状态和力反馈；
- 对象 pose、axis、extent 和 frame transform 有独立测试；
- 方法调用图中不存在 simulator `/state`、精确 AABB 或官方 probe；
- 同一份 policy 可以分别在 Oracle 和非特权 runtime 上运行，但方法指标只取后者。

## 完整 Episode

状态：未完成。当前证据停在夹到物体后抬升滑脱。

验收条件：

- `insert_tubes` 至少出现一次可重复的稳定持握；
- 抓取、抬升、搬运、对齐、下放、释放都有可观测结果；
- 至少一次非特权完整 episode 达到任务 predicate；
- 失败报告包含第一失败阶段、约束、动作和证据。

止损：单次成功不能直接扩任务；先用固定场景重复，排除偶然成功和 gate 误判。

## 下游可行性选择

状态：未开始，依赖完整 episode。

验收条件：

- 定义候选间 `compat(current, next)` 的输入、成本和 `UNKNOWN` 语义；
- 构造局部可行但后续必死的候选对；
- 比较当前阶段贪心与向后检查；
- 消融能区分候选质量提升和下游传播本身的收益。

止损：如果下游检查几乎不改变 top-1，或改变后没有稳定收益，就收缩到“约束 gate + 当前阶段排序”。
