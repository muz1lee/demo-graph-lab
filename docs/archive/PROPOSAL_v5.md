### 0.1 主张

1. **一句话**：长程操作的失败主因不是控制不准，而是**不知道每阶段什么必须成立**、**当前选择会把后面逼进死路**。一段 demo 提供的约束链，是让「前瞻、VLM 深思、修正、修复」这些强模块变得**可组合、可归因**的结构骨架（~~预演~~ 已砍，D-24③）。

## 1. 问题与动机

真正稀缺的知识不是「怎么动」，而是「什么必须成立、按什么顺序、哪里可以松」（五类不可替代信息的完整论证见 `archive/PROPOSAL_v3.md` §1，仍是权威源）。**第一条锋刃不变：demo 的产物必须是约束图，不是轨迹、不是点位。**

长程任务的第二重困难是本文主攻对象：**前一阶段的选择决定后一阶段的可行域**。抓取方式盖住 handle，挂钩阶段就无解；管子夹在下半段，插入阶段夹爪就撞架。这类失败在选择时刻不可见——**除非选择时刻就携带下游约束，并且能在真实动力学里把后果看一眼**。

**v5 新增的动机面 = 能力缺口，不是成本缺口**：

| 事实 | 数字 | 说明什么 |
|---|---|---|
| 插入类任务全行业归零 | **最强 agent 0%**（CaP-X） | 我方英雄任务 insert_tubes 的对照基线是「全员为零」；在这个维度上省成本无意义 |
| 无结构 best-of-N 被系统性偏差击穿 | **真值奖励 BoN-8 = 42%** vs **1 次预演 + 修正 = 60%**（WAP） | 重采样治不了系统性偏差；**看后果**才治得了 |
| 去掉图结构成功率归零 | GaP | 模块的收益依赖结构存在 |
| 无课程随机探索几乎零收益 | **23.2 → 24.7**（RATs） | 玩耍需要课程，**demo 就是它缺的课程** |

**结论**：v4 把「运行期零 LLM、成本摊销」当主要可防守点，是在一个全员为零的维度上争先。v5 的可防守点换成**结构使强模块可组合可归因**。

### 2.1 L4②：下游前瞻 = `compat(c,c')` 几何谓词（**仿真预演已砍除**）

**现行机制**：$F_i(c) = \mathbf{1}[c \models \Phi_i]\cdot\max_{c' \in C_{i+1}} \mathbf{1}[\mathrm{compat}(c, c')]\cdot F_{i+1}(c')$，其中 $\mathrm{compat}(c,c')$ = 候选间几何兼容性谓词（无碰可达 / 转移可行），**采样近似**。这是 **v4 §2.1 的原方案，v4 §2 仍是权威源**；实现由 **T-BP**（k 步反传算子）承载。反传**不生成数值、不淘汰**（除 L1 硬可行外），只改排序。

## 3. 为什么是论文不是缝合怪

### 3.1 统一命题与归因主线

**约束链是运行时深思的组织者**——每个模块被同一份约束链条件化并向它归因：

| 模块 | 被链条件化的方式 | 归因去向 |
|---|---|---|
| **前瞻**（~~预演~~，D-24③） | 判据 = **链上下游约束 + `compat(c,c')`**（不是终局奖励） | 阶段 × 约束 |
| VLM 选择 | **必须引用链上约束** | 节点 × 约束 |
| 修正 | 方向由**差了哪条约束**决定 | 约束 |
| 修复 | 定位到**节点 × 约束** | 节点 × 约束 |
| 进度对齐 | 按**链上阶段**分段 | 阶段 |

## 4. 实验设计

### 4.1 任务与对照

| 项 | 定义 |
|---|---|
| **英雄任务** | **insert_tubes**——插入类，**全行业 0%**（CaP-X 最强 agent）。这是「有没有效果」一眼可判的任务，也是最诚实的对照：**对手不是某个更高的分数，是零** |

### 4.2 消融阶梯（CaP-X Fig8 风格逐级加装）

| 级 | 臂 | 加装了什么 |
|---|---|---|
| ⓪ | 裸编译 policy | L2 产物直接跑 |
| ① | + 确定性约束排序 | L4① |
| ② | + **compat 前瞻**（~~仿真预演~~，D-24③） | L4② |
| ③ | + **VLM 深思（±demo 证据）** | L4③——**归因主消融** |
| ④ | + 修正阶梯 | L7①②③ |
| ⑤ | + 修复 | L7④ |

**「有链 vs 无链」成对消融（归因主线）**：③ 级的 **±demo 证据**是主消融——同一个 VLM、同一套渲染、同样的预算，唯一差异是**它能不能看到 demo 关键帧与约束**。② 级配对为「**按链上下游约束前瞻 vs 只看本阶段可行**」（v5.1 改写：原「按链 gate 判 vs 只判终局」是预演口径，随 D-24③ 作废；`compat` 口径下的配对是**开不开递归项**——v4 §2.1 已注明「**关掉递归项即得贪心臂**」，消融干净性不变），⑤ 级配对为「带节点归因 vs 裸 trace」。

### 4.3 保留项与纪律

- **保留实验**：歧义对（E-AMB，v4 §6.1，存亡属性不变）；**链长 scaling**（E-CHAIN——下游可行性由 **`compat(c,c')` 谓词**承载，T-BP；~~真仿真预演~~ 已砍，D-24③）。
- **纪律**：debug / eval **seed 严格分离** + 评测锁定（ASPIRE）；判据**预注册**（T-REG，已在执行）；**VLM 排序不打分**；**文字差分不喂原图**（CaP-X 实测回灌原图更差）。

## 5. 风险与止损

| 风险 | 表现 | 止损 |
|---|---|---|
| ~~**预演耗时**~~ → **`compat` 覆盖面**（v5.1 换轴，D-24③） | ~~每次决策 fork 仿真，ep 时长爆炸~~ ← **风险随预演砍除消失**。**新风险**：`compat(c,c')` 可能昂贵或不完备，反传价值依赖它比「执行了才知道」便宜且不太错（v4 §10 开放问题 #11） | **链前缀截断长度可调**（口径不变）；覆盖面由 E-CHAIN 的 $\kappa$ 旋钮部分探测；不完备时退回**只做 L1+L2 两层**，主张收缩（见本表倒数第二行） |
| **VLM 系统性偏差** | 排序稳定地偏向错误候选 | **约束链前瞻 + 邻域网格**（5 位置 × 3 yaw）+ **gate 残差回灌**，**不靠重采样**——WAP 已证 BoN-8（42%）打不过「看后果 + 修正」（60%）。⚠️ v5.1 中「后果」来自**真实执行的 gate**，不是预演（D-24③），因此该止损**只在阶段间生效**，阶段内首次选择无后果可看——**这是砍除预演后新增的敞口，如实记账** |
| **修复过拟合** | 改代码把 eval seed 刷穿 | **seed 分离 + 3 次上限 + 禁 seed 分支** |
| ~~**预演被质疑作弊**（在仿真里用仿真预演）~~ | ~~审稿人指「你用 GT 动力学」~~ | **风险已消除（D-24③ 砍除预演）**——这正是砍除的理由之一（循环论证嫌疑）。`compat` 谓词只用**几何可达/无碰**，不调用仿真动力学，无 GT 动力学依赖 |
| **玩耍撞内部二篇** | 与 skill library 方向撞车 | 最小版或**纯接口**（D-23⑤） |
| **反传/深思从不改 top-1**（继承 v4 §9 首行，仍是最大风险） | 消融 ②③ 级无增量 | 主张收缩为「约束判成败」（gate-only），论文降级为系统贡献 + benchmark |
| 约束抽取不稳（继承 v4） | 同 demo 两次结构不同 | 退到「人给图结构 + 自动填洞」，主张收缩到绑定与深思层，明写 |

**v5 新增的诚实交底**：运行时有 LLM 之后，v4 的「成本摊销」不再是可防守点。成本 / 延迟表**仍然要报**（每集调用次数、wall time、$/ep），但定位是**如实记账**，不是卖点（D-23 影响④）。
