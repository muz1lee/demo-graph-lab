## 0. TL;DR

### 0.1 主张

1. **一句话**：一段 demo 教的不是轨迹，而是**每个阶段的 preimage**——「什么必须成立，后面才还有救」。方法把这些定性 preimage 编译成约束链，运行期把**下游阶段的可行性反向传播回当前候选的排序**（demo-conditioned goal regression）。
2. **唯一算法主张（脊椎）**：约束链上的后向可行性传播改变当前决策。局部最优的抓取 ≠ 下游可行的抓取；只有携带链结构的方法能在选择时刻看到三步之后的死路。
3. **两条证据**：① **歧义对**——同一条欠定指令 + 两段不同 demo → 两套不同但各自合法的策略（证明结构信息真的来自 demo，不来自常识或指令）；② **干预 + 归因**——do(constraint) 按预注册方向改变排序、失败定位到「节点 × 约束」，**降级为评测机制不作 headline**（单独作贡献已被 Li & Brock / GaP / ASPIRE 占位）。
4. **招牌图**：链长 2→5 的 scaling 曲线——各类贪心随链长几何衰减，反传法保持平坦（E-CHAIN，§6.3）；理论孪生为分离定理（§4）。

### 0.2 措辞纪律（novelty 的防线画在哪）

- 反传/goal regression 是古典思想（STRIPS goal regression；Lozano-Pérez, Mason & Taylor 1984 preimage backchaining；Burridge, Rizzi & Koditschek 1999 funnel composition）。**本文不声称发明它**——声称的是它的**首次可计算实例化**：preimage 规格不再靠解析几何手算，而是由 VLM 从单段 demo 提取为定性约束 + typed holes；preimage 计算不再要求闭式解，而是在运行期采样候选集上近似完成。
- 「demo→code」「结构化中间表示」本身不作新颖性结论（`AGENTS.md` §纪律）。可防守面 = 具体机制（反传改变 top-1）+ 定理 + 招牌图 + benchmark。
- **不声称**抽取的约束是最小/必要集，只声称「足以且可控地引导候选选择」（D-18；这是绕过单 demo 可识别性质询的 scope 决定）。

## 1. 问题与动机（继承 v3 §1，本节只加外部证据）

真正稀缺的知识不是「怎么动」，而是「什么必须成立、按什么顺序、哪里可以松」——五类不可替代信息（歧义消解 / 技巧 / 容差 / 恢复结构 / 前后依赖）的完整论证见 v3 §1，全部是关系型/离散型/分级型，没有一类天然是 6-DoF 数值。**第一条锋刃不变：demo 的产物必须是约束图，不是轨迹、不是点位。**

**新增外部定量证据**（进论文动机段）：WAP（arXiv 2607.27599）实测 π0.5 在布局迁移上 6 任务中 5 个 **0%**，失败模式 =「沿用训练布局的运动先验，在原目标坐标附近空抓」——把任务知识烧进权重的路线，学到的正是我们拒绝提取的那种度量绑定；这是 D-03「度量常数是泛化死穴」的外部佐证。

而长程任务的第二重困难是本文的主攻对象：**前一阶段的选择决定后一阶段的可行域**。抓取方式盖住了 handle，挂钩阶段就无解；管子夹在下半段，插入阶段夹爪就撞架。这类失败在选择时刻不可见——除非选择时刻就携带下游约束。

## 2. 脊椎：约束链上的后向可行性传播

### 2.1 形式化梗概

任务被编译为阶段链 $S_1 \to S_2 \to \cdots \to S_L$（拓扑来自 demo，Phase 0 已达标：micro P=0.931 / R=0.865）。每阶段 $S_i$ 携带：

- **定性约束集** $\Phi_i$（demo 提取，封闭词表，零度量字面量——D-03）；
- **typed holes**：待运行期绑定的自由度（抓取位姿槽、放置槽、方向槽）；
- **候选集** $C_i$：运行期由感知/生成器产出的数值候选（洞由候选填，不由文字填——v3 §2.1）。

定义**近似可行性**（对采样候选集、谓词化约束的递归）：

$$F_L(c) = \mathbf{1}[c \models \Phi_L], \qquad F_i(c) = \mathbf{1}[c \models \Phi_i] \cdot \max_{c' \in C_{i+1}} \mathbf{1}[\mathrm{compat}(c, c')] \cdot F_{i+1}(c')$$

其中 $\mathrm{compat}(c,c')$ 是候选间兼容性谓词（例：这个抓取位姿下，那个放置位姿是否无碰可达）。**候选排序 = 漏斗 L2 偏好序，再按 $F_i$（或其软化版本）重排**——反传不生成数值、不淘汰（除 L1 硬可行外），只改变排序，与排序偏好裁决（2026-07-30）同构。

贪心法只看 $\mathbf{1}[c \models \Phi_i]$ 与局部质量；反传法多看一项 $\max_{c'} F_{i+1}$。**全部差异就在这一项**——这使消融干净：关掉递归项即得贪心臂，中间档 $k$ 步截断反传给出深度谱。

### 2.2 与经典 preimage 的对应

| 经典概念（LMT 1984 / BRK 1999） | 本文对应物 | 差异 |
|---|---|---|
| goal region | 末阶段约束集 $\Phi_L$ | 由 demo 提取，非人工给定 |
| preimage（能到达 goal 的状态集） | $\{c : F_i(c)=1\}$ | 解析集合 → 采样候选集上的近似 |
| preimage backchaining | $F_i$ 的递归计算 | 闭式几何 → 谓词 + 兼容性采样 |
| funnel / 入口条件 | 阶段 gate（验收谓词） | gate 判据与选择判据同源于 $\Phi$（双消费者） |
| funnel composition 的组合保证 | 分离定理（§4）的目标形态 | 确定性保证 → 候选覆盖假设下的概率陈述 |

这张表进论文 related work 首段：**先于审稿人写明经典对应，把「这是古典 idea」从攻击变成叙事**——40 年前 preimage 靠手算解析几何，只在积木世界可行；基础模型第一次让 preimage 规格可以从一段演示视频里读出来。

### 2.3 与三层漏斗的关系

v3 §2.1 的漏斗结构不变（L1 硬可行唯一淘汰层 / L2 偏好排序 / L3 下游反推）。变化只有一处：**L3 从「允许改序的附件」升格为方法主体**，并从「下游一步」推广为「链到底的 $k$ 步递归」。v3.1 的「L3 不进 MVS、报表只写两层」条款随之作废——**L3 就是论文，必须进关键路径**（任务 T-BP，见 `TODO.md`）。

## 3. 版本空间鲁棒反传（把不可识别性变成机制）

**审稿人最强的一击**：「单段 demo 凭什么识别出约束集？成功不蕴含边界。」D-18 的防御性回应是不声称最小性；本节是进攻性回应：**承认不可识别，在不确定性上做规划。**

- 提取器的 k=5 自一致性采样（Phase 0 已在跑）不再只投票取众数：**保留全部候选约束链为版本空间 $V = \{G_1,\dots,G_k\}$**。
- 候选排序从单一 MAP 链的 $F_i$ 改为对版本空间的鲁棒聚合：$\mathrm{score}(c) = \min_{G \in V} F_i^G(c)$（worst-case）或 $\mathbb{E}_{G}[F_i^G(c)]$（期望），二选一在 T-REG 预注册。
- **可证伪预测**（E-ROB，§6.4）：歧义 demo 上鲁棒反传显著优于 MAP 反传；干净 demo 上两者持平。两个方向都有信息量——持平处证明便宜，分离处证明价值。
- **附带产出**：版本空间分歧度 = 「要不要第二段 demo」的信号。demo 数 1→2→3 时版本空间收缩、行为收敛的曲线（demo 作为约束证据的边际价值）是相邻工作没画过的图，作为论文加分图，不立门槛。
- 成本：零新增 LLM 调用（采样已存在）；工程为纯排序层改动（任务 T-ROB，D0 后开工）。

## 4. 理论目标：分离定理

**目标形态**：构造链式任务族 $\mathcal{T}(L, \kappa)$（链长 $L$、阶段间耦合强度 $\kappa$），证明：

- **下界**：任何只依赖当前阶段信息的选择器（含带任意单调偏好的贪心），成功率 $\le (1-\epsilon(\kappa))^{L-1}$——随链长几何衰减；
- **上界**：$k$ 步反传选择器在候选覆盖假设（每阶段候选集以概率 $\ge 1-\delta$ 含可行候选）下成功率 $\ge 1 - L\delta$——与链长近似无关；
- **推论**：带回溯的贪心可以达到同等成功率，但期望执行代价随 $L$ 指数增长（回答「回溯不就行了」）。

**纪律**：定理的对抗构造必须与生成器（§6.3）的耦合旋钮 $\kappa$ 同构——理论里的任务族就是实验里能跑的任务族，图和定理互为证据。模板参照 WAP Theorem 1–3 的 contextual 分解风格（demo 供给约束报酬 $r_c$、感知供给状态 $s$）。

**降级路径（不阻塞任何实验）**：完整定理 → 受限任务族上的命题 → 纯实证（E-CHAIN 单独扛招牌）。PI 亲自推导，W1 起纸面开工（任务 T-THM）。

## 5. 运行期形态与三条硬边界

**运行期回到零 LLM**（D-18 恢复 D-01）：demo → 图（离线，LLM）→ policy（编译一次，LLM）→ **执行（零 LLM）**：候选生成、漏斗、反传排序、gate 全部确定性计算。L5 在线修正整层砍除——摊销与可审计两条卖点全额保留，成本/延迟对照表（vs per-episode VLM 与 ReAct 路线）回到卖点位。

冻结的可操作检验收敛为两条（v3 §5 的交换测试随修正器一起消失）：**字面量扫描**（策略程序出现场景度量字面量即失败，自动化）；**冻结协议**（编译后 code digest 固定，D/E seed 分离，运行期只有感知返回值变化）。

三条硬边界：

1. **验收独立**：方法路径的任何组件不参与成败判定；gate 的 `passed` 由 `gates.py` 几何谓词计算，verifier 类模型只允许在 evaluator 侧出 shadow 报告（D-18 推论，PI 可复议）。
2. **运行期零 LLM**（D-01）：方法路径（工位 B）执行期无模型调用；工位 A（标定）/ 工位 C（基线）不受限。
3. **特权量只进 evaluator**（D-04 不变）：oracle 態只作上界/归因/评测，`privileged_oracle` 不得出现在主方法 provenance 链。

## 6. 实验计划（概念层；判据注册走 T-REG）

**准入条件不变**：每次失败可定位到「节点 × 层」；做不到归因的实验不计入结论。

### 6.1 E-AMB（歧义对，存亡实验）

同一条欠定指令，两段 demo 演示不同的合法解法（选左管 vs 选右管；叠大碗在下 vs 按颜色叠）。判定：两套编译产物**可区分**（选择了不同目标/不同抓法）且**各自执行成功**；交叉检验：policy_A 在 demo_B 意图下的判定不同。素材由生成器歧义旋钮构造（T-GEN-3；现有视频无目标歧义，D-13 的素材任务在此落地）。**存亡属性**：E-AMB 失败 = 结构信息并非来自 demo，主张 ① 的证据链断裂。

### 6.2 E-DO（干预协议，评测机制）

do(constraint)：改 demo 图中单条约束（region 标签、order 边），预注册预期方向，检验候选排序/top-1 按方向改变。这是 CC-0/CC-1′/CC-2′ 判据的论文化，不作 headline。

### 6.3 E-CHAIN（链长 scaling，招牌图）

任务族由生成器产出：链长 $L \in \{2,3,4,5\}$ × 耦合强度 $\kappa$ 两档 × ≥5 seeds。**对照臂**：

| 臂 | 定义 | 预期 |
|---|---|---|
| B0 无约束贪心 | L1 硬可行 + 生成器置信度 top-1 | 随 $L$ 几何衰减 |
| B1 单步 task-aware | L1 + L2（本阶段约束偏好序）top-1，零下游 | 随 $L$ 几何衰减（略缓于 B0） |
| B2 回溯贪心 | B1 + 失败回溯重选（预算封顶） | 成功率可平，执行代价随 $L$ 陡增 |
| **OURS** | $k$ 步反传排序 | 平坦 |
| B3 ReAct-replanning | 每步在环 VLM 重规划（工位 C，D-01 豁免位） | 成功率可平，**每集成本/延迟 10–100×** |

一张图报成功率 × 链长；伴图报 B2/B3 的代价曲线——同时回答「为什么不回溯」「为什么不 ReAct」，成本表从 v2 的静态对比升级为随链长的动态对比。

**感知态口径（已裁决，D-20）**：E-CHAIN 主数字 = **非特权感知链**（P1-04/05/06/07 必做、不可裁剪）；oracle 态数字只作上界与管线试点（D-05 标签纪律）。上位原因：RoboDojo 官方 evaluator 为非特权观测，榜单轨（D-20，第二 headline：上榜 + Long-Horizon 维度领先，激活门 = D0 ∧ 官方通道开放，预算 ≤15 人日）使最严口径成为唯一口径；论文内受控 baseline = CaP-Agent0（同 API、同预算、无 demo），两层不混报纪律见 `archive/ARCHIVE.md` §5.4。

### 6.4 E-ROB（版本空间鲁棒反传）

MAP 链反传 vs 鲁棒反传 × {歧义 demo 组, 干净 demo 组}。预注册预期：歧义组分离、干净组持平（§3）。依赖 T-GEN-3 素材与 T-ROB 实现。

### 6.5 存续实验

E-CAUSAL 批（约束因果链，L0/L1）、E-GATE 批、A1 三臂消融（全图/仅点位/无 demo）照旧，出处 `EXECUTION.md` §1 与 `TODO.md`。20-seed 双阈值（≥16/20、≥12/20）降级为执行基底的健全性检查，不作论文主数字（D-18；PI 可复议）。

## 8. 明确不做（合并 v3 §11 + D-18 砍单）

- 不做端到端训练，不产出 VLA。
- **不做运行期在线修正（L5 已整层砍除）**；执行误差由 gate 的 retry/reject 与绑定档位承接。
- **不做 G1/G2/G3 抽象层级消融**（CaP-X 已覆盖，我方样本量不够 finding）。
- **不以真机闭环为主结果前提**（真机与 motion planning 通路为背景任务）。
- **不使用任何「最小/必要约束集」措辞**。
- 不在运行期引入人手任务 yaml（v3 §8 纪律不变）。
- 本篇不做技能库积累与抽象层自动发现（第二篇候选）。

## 10. 开放问题

继承 v3 §12 仍活的：#1 表达完备性、#2 容差来源、#3 可组合性（第二篇接口）、#5 gate 与选择同源的循环风险、#8 跨节点边缘合格、#9 偏好序无独立参照、#10 cone 处置（未决 #4）。随 L5 砍除而消解的：#4/#6/#7。新增：

11. **兼容性谓词 $\mathrm{compat}(c,c')$ 的覆盖面**：两阶段候选间的可行性检查（无碰可达、转移可行）本身可能昂贵或不完备；反传的价值依赖它比「执行了才知道」便宜且不太错。目前无原理性答案，E-CHAIN 的 $\kappa$ 旋钮部分探测它。
12. **版本空间大小 k 的原理**：k=5 是 Phase 0 的工程遗产，不是统计量；分歧度饱和曲线（加样本不再扩大 V）是候选答案，v1 不承诺。
13. **生成器的三旋钮是否正交**：链长、耦合、歧义在构造上可能纠缠（长链天然更歧义）；T-GEN-1 spec 阶段必须给出三旋钮的独立性检验设计。
