## 0. TL;DR

### 0.1 主张

1. **一句话**：长程操作的失败主因不是控制不准，而是**不知道每阶段什么必须成立**、**当前选择会把后面逼进死路**。一段 demo 提供的约束链，是让「预演、VLM 深思、修正、修复」这些强模块变得**可组合、可归因**的结构骨架。
2. **统一命题（论文的脊梁）**：**约束链是运行时深思的组织者。** 每个模块被同一份约束链条件化，并向它归因——预演判据 = 链上 gate；VLM 选择必须引用链上约束；修正方向由差了哪条约束决定；修复定位到「节点 × 约束」；进度对齐按链上阶段分段。
3. **结构在手 vs 结构缺席**（三个外部反例，这是主张的负面证据）：GaP 去掉图结构成功率**归零**；WAP 无结构 best-of-N 被系统性偏差击穿——**真值奖励 BoN-8 = 42%，输给「1 次预演 + 修正」的 60%**；RATs 无课程随机探索几乎零收益（**23.2 → 24.7**）。
4. **八篇各占一角，没有一篇同时拥有**：示范给出的显式结构 + 执行前的真实预演 + 阶段级验收归因。

### 0.2 措辞纪律（novelty 的防线画在哪）

- **不声称发明反传 / goal regression**（STRIPS goal regression；Lozano-Pérez, Mason & Taylor 1984 preimage backchaining；Burridge, Rizzi & Koditschek 1999 funnel composition）。承认经典对应，表述为「经典 preimage 回传在单 demo 定性约束链上的首次可计算实例化」（v4 §2.2 表进 related work 首段，纪律不变）。
- **不声称发明预演**。model-based lookahead / rollout / MPC 是老思想；WAP 已用 learned world model 做想象 rollout。我方声称的是**具体实例化**：fork 真仿真状态、按**链上 gate** 判预演结果、只产**排序建议**。
- **不声称发明 VLM-in-the-loop**。声称的是**被约束链条件化的** VLM——它必须引用链上约束，且只出离散量。
- **不声称**抽取的约束是最小/必要集，只声称「足以且可控地引导候选选择」（D-18 该条**不变**）。
- **「demo→code」「结构化中间表示」本身不作新颖性结论**（`AGENTS.md` §纪律）。可防守面 = 统一命题 + 「有链 vs 无链」成对消融 + 预演的空位。

## 1. 问题与动机

真正稀缺的知识不是「怎么动」，而是「什么必须成立、按什么顺序、哪里可以松」（五类不可替代信息的完整论证见 `archive/PROPOSAL_v3.md` §1，仍是权威源）。**第一条锋刃不变：demo 的产物必须是约束图，不是轨迹、不是点位。**

长程任务的第二重困难是本文主攻对象：**前一阶段的选择决定后一阶段的可行域**。抓取方式盖住 handle，挂钩阶段就无解；管子夹在下半段，插入阶段夹爪就撞架。这类失败在选择时刻不可见——**除非选择时刻就携带下游约束，并且能在真实动力学里把后果看一眼**。

**v5 新增的动机面 = 能力缺口，不是成本缺口**：

| 事实 | 数字 | 说明什么 |
|---|---|---|
| 插入类任务全行业归零 | **最强 agent 0%**（CaP-X） | 我方英雄任务 insert_tubes 的对照基线是「全员为零」；在这个维度上省成本无意义 |
| 无结构 best-of-N 被系统性偏差击穿 | **真值奖励 BoN-8 = 42%** vs **1 次预演 + 修正 = 60%**（WAP） | 重采样治不了系统性偏差；**看后果**才治得了 |
| 去掉图结构成功率归零 | GaP | 模块的收益依赖结构存在 |
| 无课程随机探索几乎零收益 | **23.2 → 24.7**（RATs） | 玩耍需要课程，**demo 就是它缺的课程** |

**结论**：v4 把「运行期零 LLM、成本摊销」当主要可防守点，是在一个全员为零的维度上争先。v5 的可防守点换成**结构使强模块可组合可归因**。

### 2.1 L4②：仿真状态克隆预演（v5 的新核心模块）

**机制**：fork 当前 Genesis 状态 → 虚拟执行每个候选 **+ 后续链前缀** → 收集各阶段 gate 结果 → **下游可行性精确计算**（v4 §2.1 的 $\max_{c'} F_{i+1}$ 由采样近似升级为精确值）。

**这是全场空位**——八篇里没有一篇占住：

| 方法 | 有无执行前预演 | 缺陷 |
|---|---|---|
| CaP-X | **无** | — |
| GaP（运行时） | **无** | — |
| ASPIRE | **无** | 纯失败后探索 |
| WAP | **有** | learned world model **接触失真（原文自认）** + **17 秒/次** |
| **我方** | **有** | **真仿真 fork 把 WAP 的两个缺陷同时消掉** |

**WAP 组件消融的预期增益**（我方按其报告的组件增益预估自身收益上界）：方向修正 **+8~24 分**、邻域网格 **+6~14 分**（5 位置 × 3 yaw，δ ≈ 半物体尺寸）、policy 预演 **+4~14 分**。

### 2.2 L4③：demo 条件化 VLM 深思

**机制**：候选以**覆盖层渲染**进场景图，VLM 对照 **demo 关键帧**与约束**排序**，且**必须引用支持该选择的那条约束**。

- **表示法照抄 VIA**（其实测有效）：hover 验证回读 / 蓝色目标夹爪网格 / 每视图用途说明 / **文本 waypoint 进 prompt 77% → 100%**。
- **纪律：不打分、不出连续量**。依据 WAP——**VLM 无度量接地时只能做符号判断**，其全局修正也只输出 `{-1, 0, 1}`。
- **分工依据（VIA）**：最强 agent 在环合法（长程 **100%**，Fable **88%**），但有 **8 mm 精度天花板**⇒ **连续精度归规划 / 控制，VLM 只做离散选择**。

### 2.3 L7：修正阶梯四级

| 级 | 机制 | 论文依据 |
|---|---|---|
| ① | gate 重试 | — |
| ② | **有界 VLM 修正**：看多视角含手摄 + **预演后果**，输出 `{-1,0,+1}` × 固定步长离散修正 | WAP：**VLM 生成时物理盲，但看到后果后能认出问题**——这是「必须先预演再让它修」的直接依据 |

### 2.4 加分轴（本篇只留接口，不做）

**demo 流形上的有界玩耍**：在约束链限定的（阶段，洞）空间用 RATs 的**稀有度 × 甜点区** $N(\tau)\cdot F(\tau)$ 调度 **50 次量级**预练，绑定挂可靠性生命周期（实验 → 验证 → 弃用 + Wilson 成功率）。

- **本篇不做**（D-23⑤）：内部撞车面已知（第二篇 skill library 方向）。只留接口。

## 3. 为什么是论文不是缝合怪

### 3.1 统一命题与归因主线

**约束链是运行时深思的组织者**——每个模块被同一份约束链条件化并向它归因：

| 模块 | 被链条件化的方式 | 归因去向 |
|---|---|---|
| 预演 | 判据 = **链上 gate**（不是终局奖励） | 阶段 × gate |
| VLM 选择 | **必须引用链上约束** | 节点 × 约束 |
| 修正 | 方向由**差了哪条约束**决定 | 约束 |
| 修复 | 定位到**节点 × 约束** | 节点 × 约束 |
| 进度对齐 | 按**链上阶段**分段 | 阶段 |

**消融设计即论证**（§4.2）：同一模块「**有链 vs 无链**」成对——VLM 看 demo vs 不看；预演按链 gate 判 vs 只判终局；修复带节点归因 vs 裸 trace。**每一分增益都能归因到链**。

### 3.2 八篇占位一句话表

| 论文 | 占了什么 | 我方的空位 |
|---|---|---|
| **CaP-X** | code-as-policy + 失败后改代码 | **插入类全行业归零（最强 agent 0%）**；我方主打 insert_tubes ✅实测已推进到**指尖触管** |
| **GaP** | 图策略 + 自学习 | 图来自**语言 + CAD，无 demo 入口**；**运行时验收 no-op** |
| **ASPIRE** | 失败驱动技能库 | **纯失败探索、无 demo**；技能库会腐化；**无预演** |
| **WAP** | world model 想象 rollout | **有预演但 learned WM 接触盲**；**无验收、无 demo** |
| **HOST** | 单视频 demo | **62% 靠 19.3 万条同平台预训练**；无结构、失败不可归因、不处理链式耦合（窗口单调不可回退） |
| **VIA** | 最强 agent 在环 | 在环合法（长程 **100%**，Fable **88%**）但 **8 mm 精度天花板**——为我方**分工依据**背书 |

| **DoID** | 数据管线 | **自认无场景级推理**（引作我方卖点） |

## 5. 风险与止损

| 风险 | 表现 | 止损 |
|---|---|---|
| **预演耗时** | 每次决策 fork 仿真，ep 时长爆炸 | **只在关键决策点**预演（WAP 口径：每任务 1–2 次）；**链前缀截断长度可调** |
| **VLM 系统性偏差** | 排序稳定地偏向错误候选 | **渲染后果闭环 + 邻域网格**（5 位置 × 3 yaw），**不靠重采样**——WAP 已证 BoN-8（42%）打不过预演+修正（60%） |
| **修复过拟合** | 改代码把 eval seed 刷穿 | **seed 分离 + 3 次上限 + 禁 seed 分支** |
| **预演被质疑作弊**（在仿真里用仿真预演） | 审稿人指「你用 GT 动力学」 | **只产排序建议**，验收由**独立 gate** 判；真机时**预演器可换 learned WM**（引 WAP 接口）——**如实写明**，不藏 |
| **玩耍撞内部二篇** | 与 skill library 方向撞车 | 最小版或**纯接口**（D-23⑤） |
| **反传/深思从不改 top-1**（继承 v4 §9 首行，仍是最大风险） | 消融 ②③ 级无增量 | 主张收缩为「约束判成败」（gate-only），论文降级为系统贡献 + benchmark |
| 约束抽取不稳（继承 v4） | 同 demo 两次结构不同 | 退到「人给图结构 + 自动填洞」，主张收缩到绑定与深思层，明写 |

**v5 新增的诚实交底**：运行时有 LLM 之后，v4 的「成本摊销」不再是可防守点。成本 / 延迟表**仍然要报**（每集调用次数、wall time、$/ep），但定位是**如实记账**，不是卖点（D-23 影响④）。
